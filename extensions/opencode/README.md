# OpenCode Zen FRIDAY provider

Official FRIDAY provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
openclaw plugins install @openclaw/opencode-provider
openclaw gateway restart
```

## Docs

See `docs/providers/opencode.md` in the FRIDAY repository, or the published
docs at `https://docs.openclaw.ai/providers/opencode`.
